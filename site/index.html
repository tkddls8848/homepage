공공기관 정보시스템의 서버·스토리지·HCI 가상화 인프라를 제안합니다. 일하면서 필요한 도구는 직접 만들어 운영합니다.

트라이얼정보통신 시스템사업부에서 2020년부터 RFI 대응, 하드웨어 구성과 견적, 제안서 작성을 맡아 왔습니다. 퇴근 뒤에는 Cloudflare Workers 와 AWS 위에서 견적서 변환기, 나라장터 공고 조회, 주식 시장 브리핑 같은 서비스를 만듭니다.

제안 업무를 하며 내부 구성원, 고객, SI 사이에서 기술 용어가 통일되지 않아 소통이 어려웠던 경험이 있습니다. 그래서 업계 기사와 하드웨어 벤더 레터를 매일 챙겨 보고, 기술 자격을 따며 하드웨어부터 소프트웨어까지 이해의 폭을 넓히고 있습니다.

  1. 2022.08국민건강보험공단

    진료지원 시스템 인프라 구축. 주제안서 작성에 참여하고 서버·스토리지 견적을 맡았습니다.x86 서버, 스토리지, 가상화·보안 솔루션 수주

  2. 2021.12국민연금공단

    차세대 4대사회보험 정보연계 플랫폼 구축. RFI 와 제안서를 쓰고, 일반 RAID 와 분산 RAID 의 비교 자료를 만들었습니다.IBM UNIX 서버 3식, SAN 스위치 4식, SAN 스토리지 4식 수주

  3. 2021.09국민연금공단

    공동 연계급여정보시스템 재구축. 서버 제안을 스토리지까지 넓혀 기존 Hitachi 스토리지 자리를 가져왔습니다.IBM 서버 3식, 스토리지 2식 수주

  4. 2020.05한국고용정보원

    AI 기반 일자리매칭시스템 구축 2차 사업의 제안서를 작성했습니다.IBM UNIX 서버 3식 수주
